I kept hitting the same wall: I wanted a place to write daily, but every option felt
like a detour. A hosted blog meant giving up ownership. A separate repo meant another
thing to maintain. So I did the obvious thing in hindsight — I grew the writing *inside*
the portfolio I already had.

The content lives as markdown in git. I write in Obsidian, flag a note `publish: true`,
and it shows up here. That's the whole pipeline.

> [!note] The metric that matters
> The goal isn't readers. It's the habit. Did I write this week? That's the only number
> I'm tracking.

See [[on owning your words]] for the longer version of why ownership drove this.

## What's here

- **Posts** — longer thinking-out-loud pieces like this one.
- **Devlogs** — build-in-public notes threaded under a project.
- **Notes** — short, rough, and allowed to stay that way.
